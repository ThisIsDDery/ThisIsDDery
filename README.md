### 🧪 What I do

I came up through manual QA on consumer fintech apps, and now spend my days making quality **automatic**: mobile end-to-end suites, the CI that runs them every night, and the AI agents that keep them healthy.

- **Mobile E2E at scale** — maintain a Maestro suite for a Kotlin Multiplatform app, running on **Android emulators and iOS simulators** across several country markets, with day/week/new scheduling tiers.
- **AI-driven test generation** — helped build a pipeline where an LLM agent reads an app commit, its ticket and its design, then writes and self-verifies a new E2E test and opens the PR.
- **Agentic QA workflows** — author reusable agent *skills* for CI failure triage, selector-drift debugging, bug priority & regression classification, and Jira bug filing, each with a human-approval gate before anything is sent.
- **CI/CD for test infrastructure** — GitHub Actions orchestration, sharded parallel runs, device setup scripts, flake detection, and reporting into Slack and PR comments.
- **Test data & environments** — API-driven test-user provisioning, feature-flag control, and mock push/camera infrastructure so flows that "can't be automated" can be.
- **Bug advocacy** — file reproducible, priority-justified bug reports and track them through to a fix.
